Project

Export as an overhaul mod

Builds a .ts4script that applies this overhaul when a zone loads. Sims are matched by name and household. Use it on a new save, or load an existing save and run simoverhaul.apply in the cheat console to update that save.

Studio tips

  • Tray files are read-only. Nothing in your library is overwritten.
  • entries come from your own Mods folder.
  • Batuu content is hidden by default in the catalogs.
  • Export writes to the exports folder next to this app.
